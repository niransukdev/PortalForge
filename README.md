# PortalForge

PortalForge: A scalable, API-based infrastructure for data-driven applications, leveraging caching, acting as a secure gateway and centralized hub.

PortalForge is aimed at developers who need a straightforward, dependable solution.

- python

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/PortalForge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

PortalForge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
